# SISUPA

O **SISUPA** é uma aplicação web desenvolvida para a centralização, unificação e divulgação de projetos acadêmicos dentro do ambiente universitário. A plataforma funciona como um feed dinâmico onde os projetos do campus podem publicar atualizações de suas atividades, anunciar eventos, abrir processos seletivos e disponibilizar páginas institucionais com informações detalhadas para a comunidade.
